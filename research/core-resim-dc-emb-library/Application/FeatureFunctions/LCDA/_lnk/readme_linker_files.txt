If you are using the provided Makefile LCDA_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option LCDA_GENERATE_LCF_FILES or by calling "make -f LCDA_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated LCDA linker files are named:
core2_lcda_bss.lcf
core2_lcda_cal_data.lcf
core2_lcda_data.lcf
core2_lcda_txt.lcf
