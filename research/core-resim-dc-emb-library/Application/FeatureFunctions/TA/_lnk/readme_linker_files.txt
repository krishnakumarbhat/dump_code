If you are using the provided Makefile TA_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option TA_GENERATE_LCF_FILES or by calling "make -f TA_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated TA linker files are named:
core2_ta_bss.lcf
core2_ta_cal_data.lcf
core2_ta_data.lcf
core2_ta_txt.lcf
