If you are using the provided Makefile CED_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option CED_GENERATE_LCF_FILES or by calling "make -f CED_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated CED linker files are named:
core2_ced_bss.lcf
core2_ced_cal_data.lcf
core2_ced_data.lcf
core2_ced_txt.lcf
