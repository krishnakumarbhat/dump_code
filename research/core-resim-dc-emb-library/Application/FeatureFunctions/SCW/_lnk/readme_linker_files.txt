If you are using the provided Makefile SCW_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option SCW_GENERATE_LCF_FILES or by calling "make -f SCW_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated SCW linker files are named:
core2_scw_bss.lcf
core2_scw_cal_data.lcf
core2_scw_data.lcf
core2_scw_txt.lcf
