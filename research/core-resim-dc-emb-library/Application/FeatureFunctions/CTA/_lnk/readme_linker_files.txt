If you are using the provided Makefile CTA_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option CTA_GENERATE_LCF_FILES or by calling "make -f CTA_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated CTA linker files are named:
core2_cta_bss.lcf
core2_cta_cal_data.lcf
core2_cta_data.lcf
core2_cta_txt.lcf
