If you are using the provided Makefile ESA_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option ESA_GENERATE_LCF_FILES or by calling "make -f ESA_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated ESA linker files are named:
core2_esa_bss.lcf
core2_esa_cal_data.lcf
core2_esa_data.lcf
core2_esa_txt.lcf
