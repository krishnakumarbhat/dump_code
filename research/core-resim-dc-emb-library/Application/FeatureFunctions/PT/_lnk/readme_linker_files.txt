If you are using the provided Makefile PT_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option PT_GENERATE_LCF_FILES or by calling "make -f PT_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated PT linker files are named:
core2_pt_bss.lcf
core2_pt_cal_data.lcf
core2_pt_data.lcf
core2_pt_txt.lcf
