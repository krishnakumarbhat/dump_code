If you are using the provided Makefile Feature_Building_Kit_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option Feature_Building_Kit_GENERATE_LCF_FILES or by calling "make -f Feature_Building_Kit_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated Feature_Building_Kit linker files are named:
core2_feature_building_kit_bss.lcf
core2_feature_building_kit_data.lcf
core2_feature_building_kit_txt.lcf
