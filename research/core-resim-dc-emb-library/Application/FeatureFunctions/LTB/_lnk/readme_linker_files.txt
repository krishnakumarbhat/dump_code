If you are using the provided Makefile LTB_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option LTB_GENERATE_LCF_FILES or by calling "make -f LTB_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated LTB linker files are named:
core2_ltb_bss.lcf
core2_ltb_cal_data.lcf
core2_ltb_data.lcf
core2_ltb_txt.lcf
