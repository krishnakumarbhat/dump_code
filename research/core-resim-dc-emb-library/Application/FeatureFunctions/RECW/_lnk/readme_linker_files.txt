If you are using the provided Makefile RECW_[CUSTOMER].mak the linker files will be auto-generated by the Makefile.
Otherwise the linker files can be auto-generated with the CMake option RECW_GENERATE_LCF_FILES or by calling "make -f RECW_[CUSTOMER].mak" from the Makefile directory in a command shell.

The auto-generated RECW linker files are named:
core2_recw_bss.lcf
core2_recw_cal_data.lcf
core2_recw_data.lcf
core2_recw_txt.lcf
