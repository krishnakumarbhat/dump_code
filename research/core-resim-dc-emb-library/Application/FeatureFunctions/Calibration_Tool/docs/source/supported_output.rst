Core files
-----------

This section creates an overview of all files which can be generated by the calibration tool. For this
every optional check has been enabled.

Main calibration header file
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This file provides the following information:

 * Macro definitions for minimum and maximum boundaries
 * Macro definitions for array dimensions
 * A macro definitions for the calibration structure size
 * Calibration structure definition in different order relevant for endian switches
 * A set of functions used for updating (in case calibrations are not initialized), diagnostics, array reversing, initialization checks and
   a set of getter functions

.. literalinclude:: ../../testing/example_files/Core/cool_feature_calibration_t.h
    :language: c

Boundary check files
~~~~~~~~~~~~~~~~~~~~

This file provides checks for all given calibrations. Here it is ensured, that the given value of a calibration is in the range
of the provided boundaries in the xml files.

.. literalinclude:: ../../testing/example_files/Core/cool_feature_calibration_t_cal_check.c
    :language: c

.. literalinclude:: ../../testing/example_files/Core/cool_feature_calibration_t_cal_check.h
    :language: c

Diagnostics
~~~~~~~~~~~

This file provides a function for diagnostics. This needs to be enabled with a macro definition.
