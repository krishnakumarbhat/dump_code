# Changelog

## - Initial Version v1.0

- Suite-level test orchestration (`RunTest_Suite_IT`, `Suite_Dialog`) with retry logic, consolidated HTML reporting, and configurable sensor/injection modes.
- Robust T32/hardware handling, 48-bit compression support, and improved match-detect/tolerance/scaling accuracy.
- Embedded-only raw data collection mode with GUI configuration flags.
- Consolidated and per-test HTML reports replacing legacy report generation.
