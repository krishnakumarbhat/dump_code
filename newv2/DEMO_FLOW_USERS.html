How to run — in 3 steps

STEP 1

Open the Resim Run form

Dashboard → Runtime Map. The Resim Run form is the first card on the page.

STEP 2

Enter your files

Paste the input.txt and .simg paths (or click Browse). Press Detect to auto-fill everything else. Optionally tick "Create JIRA ticket".

STEP 3

Run Resim

Press Run Resim. The console opens, shows the progress live, and when it's done you can open the output — no need to re-run it later, it's saved in history.

Good to know: you don't need to remember anything technical — not the cluster, the account, or the commands. The page detects the project from your file path and picks the right settings for you.

How to run — in 3 steps

STEP 1

Open the KPI page

Dashboard → KPI Analysis. Choose CAN KPI or UDP KPI — the page only offers what works with your choice.

STEP 2

Add your files

Select input mode (JSON batch or HDF pair), then add your data files, config, and the output folder. Want plots too? Flip the matching switch — it's already wired for you.

STEP 3

Queue it

Press Queue through broker. Watch it in the console, then open the KPI report and plots. If the same scenario was already run, you'll be asked to just open the saved result instead.

Good to know: no setup needed. If the same run was already done before, the page notices and lets you open the saved result instead of running it again.
